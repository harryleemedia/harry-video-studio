# 把作品做成循环

只有结尾那一帧和开头那一帧完全相同，循环才是无缝的。
`styles/` 里大多数标注「不循环」的参考作品，都可以按这份清单改成循环。

## 清单
1. **没有入场。** 第 0 帧必须是一幅完成的、好看的画面，而不是一张等着元素飞进来的空页面。
   把入场构建挪到后面，或者让时钟从某段停留的中间开始。
2. **一个时钟。** 所有东西都根据 `t` 绘制（`STUDIO.play(render, { loop: true })`）。不读取任何真实时间。
3. **整数周期。** 每个波动、摇摆、上下浮动、旋转或漂移，都必须在整个时长内走完整数个周期：
   `Math.sin(2 * Math.PI * n * t / D)`，其中 `n` 为整数。用
   `grep -n "t \*\|Math.sin(t\|Math.cos(t" index.html` 找出违规写法。像 `x = t * speed` 这样的漂移，要改成摇摆或回绕。
4. **有去有回。** 每个一次性变化（变色、变形、缩放、计数）到结尾都必须回到起始值。
   把单向曲线改成先升后降的起伏，并在动作结束时精确吸附到终点值。
5. **噪点要回绕。** 用帧序号驱动的颗粒、闪烁或粒子帧必须回绕：`frame % totalFrames`。
6. **在看不见时重置。** 如果某样东西必须跳回原位（一朵云、一个计数器），就在它出画或被遮住时跳。
7. **接缝处保持运动。** 循环点前后应该有大的东西在动，这样永远不会感觉停顿。
   运行 `pacing_check.py --loop`，它也会测量跨接缝的空档。

## 证明它
`python3 scripts/loop_check.py out/draft.mp4 --project proj`
- 测试 A：画出 0 秒处和结尾处的帧（关闭单一时钟的回绕），逐像素比较。
- 测试 B：检查从最后一帧跳回第一帧的变化不大于正常的一帧步进。
两项都必须显示 PASS。
