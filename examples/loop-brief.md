# 简报示例：「Make it move」循环

你对 Claude 说的话：
> 帮我做个动态图形。16:9，9 秒，swiss-grid，要循环，文字 "Make it move."，其余用风格默认值。

Claude 据此写出的简报（技巧 3：每个形容词都变成数字）：

- 画幅：1920 x 1080，9.0 秒，30 fps，循环（9.0 秒处的帧 = 0 秒处的帧）。
- 风格：swiss-grid。底色 #FFFFFF，墨色 #111111，网格 #E6E6E6，强调色 #E4002B。Inter 900，字距 -0.04em。
- 缓动：文字落定用 expo.out 0.6 秒，离开用 power3.in 0.35 秒，方块移动用 power3.inOut 0.5 秒。
- 文字："Make" / "it" / "move." 竖向堆叠，靠左边距对齐。最后一个词会替换：move. -> loop. -> land.
- 唯一的视觉母题：红色句点。它在词与词之间跳跃，落下时被压扁。
- 节拍表：
  | 时间 | 画面内容 | 主动作 |
  |---|---|---|
  | 0.5 | 右侧 3 x 3 方块阵，留一个空位 | 一个方块滑进空位 |
  | 1.5 | 最后一个词向上滑出遮罩，新词向上滑入 | 红点跳起并落下 |
  | 2.5、3.5 | 方块继续滑动，空位绕一圈移动 | 方块移动 |
  | 4.5 | 第二次换词 | 红点跳跃 |
  | 5.5、6.5 | 方块 | 方块移动 |
  | 7.5 | 第三次换词，回到 "move." | 红点跳跃 |
  | 8.5 | 最后一次方块移动，让空位走完一圈 | 此时画面等于第 0 帧 |
- 禁用：渐变、阴影、发光、圆角、居中文字、第二种强调色、运动物体上的线性缓动。
- 检查：loop_check.py（0 秒与 9 秒必须一致），pacing_check.py（没有超过 1 秒的空档，没有短于 0.3 秒的停留）。

按这份简报做出的成品是 `styles/swiss-grid/index.html`（它在风格画廊里的视频是 `gallery/videos/swiss-grid.mp4`）。
