# 一个小组件，历经每种天空（One widget, every sky）

id: weather-widget
适合：应用和产品界面推广、功能随时间变化、状态或仪表盘故事、发布会风格揭晓、会改变状态的数据。
气质：一个精致的发布会级小组件经历一整天，镜头从不切走。
参考作品：styles/weather-widget/index.html（12 s，不循环：结束时回到开场时的同一个方形，但不是同一帧。要做成循环，见 references/loops.md）
画廊视频：gallery/videos/weather-widget.mp4

## 配色 (hex)
每个状态有天空顶部、天空底部、组件顶部、组件底部四个颜色：
- 清晨：#86BDF0, #E8F3FC, #2A78E2, #73B8F7
- 多云：#8799AE, #CED7E1, #566D86, #8A9EB3
- 下雨：#334254, #5B6B7F, #1D2939, #3A4A5F
- 雷暴：#222D3B, #3E4B5D, #121A25, #2A3748
- 夜晚：#0E1A33, #1E3263, #1A2D5A, #0B1530
- 黎明：#3A5FA6, #F7E6BC, #3468C2, #C9DCF2
- 文字：#FFFFFF。月亮：#FFFFFF 到 #ECEFF6 到 #C4CBDD。
- 强调色：#FFC94A 太阳黄（核心 #FFF6D2 到 #FFDC72 到 #FFC94A）。唯一的强调色：只用于太阳、它的光晕和黎明辉光。
- 投影带天空的色调（例如清晨用 rgba(24,78,150,0.34)）。

## 字体
- 展示字（数字）：Inter 200，300 px，字距 -0.045em，行高 0.84，等宽数字。
- 标签：Inter 600，70 px，字距 -0.012em，白色带柔和阴影。
- 屏幕上最多 3 个词。每个状态一个标签。
- 字体链接（粘贴到 <head>；所有字体均免费）：
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@200;600&display=swap">
- 中文文字用 Noto Sans SC（无衬线），从 Google Fonts 引入，因为拉丁字体没有中文字形：`<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@200;600&display=swap">`

## 缓动 (数值)
- 落定：expo.out，1.1 s。组件从缩放 0.9 到 1，上升 60 px。
- 变形：欠阻尼弹簧，1.25 s（阻尼 6.5，频率 8.2），约 7% 过冲。高度比宽度滞后 0.06 s，圆角滞后 0.03 s。
- 标签入场：expo.out，0.7 s，从下方 46 px、12 px 模糊开始。
- 标签离场：power2.in，0.3 s，向上 30 px、8 px 模糊。
- 移动（数字计数、天空颜色）：power2.inOut，约 1 s。
- 错开：标签之间约 0.16 s（旧的先离场，新的再落定）。

## 动效规则
- 一个物体从不离开画面。每次状态变化都是同一个形状的弹簧变形。
- 形状顺序：圆角方形、宽胶囊、高卡片、宽胶囊、圆角方形。
- 每次变化都落在拍上（2.5、4.5、7.5、10.0 s）。外面的天空随之变化。
- 数字始终在计数。从不跳变。
- 缓慢浮动（4 px）让组件在拍与拍之间保持生命感。
- 大时刻有物理反应：闪电让组件震一下，并让整个画面闪白。

## 标志动作
- 发布会级质感：宽而柔的阴影加紧贴的接触阴影，受光的顶边，内部顶部的光泽。
- 阳光溢出组件，温暖它的一角。
- 组件内有三层山丘，被天空里的光勾出轮廓光。
- 天气有体积感：云有受光的圆顶和暗色的底部，雨落在山上溅起水花，玻璃上有水滴。

## 构图
- 组件是主角，铺满画面：方形 880 px，胶囊 1680 x 620，卡片 720 x 940。
- 居中。标签在内部左上，大数字在左下。
- 后面的天空柔和、失焦。只有远处的云和雨，没有细节。
- 轻微的镜头暗角和极淡的胶片颗粒（4.5%）。

## 带素材
- 把组件当窗口：一个使用同样变形圆角的 div，overflow hidden，片段放在里面，object-fit cover，并缓慢推进。
- 把同一个片段放在组件后面，模糊约 42 px 并压暗，缓慢漂移。外面的世界和窗口里的一致。
- 如果缺某种天气的片段，就拿另一个来调色：暴风雨就去饱和、压暗、提高对比度。代码生成的雨、水滴和闪电保持在上层。
- 把太阳光晕、光束、受光边和颗粒保留在画面素材之上，让它依然看起来是这个组件。

## 禁用清单
- 从组件切走
- 线性或没有过冲的变形
- 太阳黄用在太阳和黎明辉光以外的地方
- 用普通圆圈拼成的泡泡纸云
- 白云滑过夜空
- 同时超过 3 个词
- 仅限 macOS 的系统字体（在其他机器上无法渲染）
