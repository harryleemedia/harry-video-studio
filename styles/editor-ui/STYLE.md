# 在专业剪辑软件里剪辑（Edited in a pro editor）

id: editor-ui
适合：“AI 帮我剪视频”演示、工具发布、工作流讲解、片头、前后对比揭晓。
气质：一款沉静的深色视频剪辑软件铺满画面，AI 光标完成一次真实的剪辑，然后应用飞散，成片开始播放。
参考作品：无，仅有规格说明（原作基于真实画面素材制作）
画廊视频：gallery/videos/editor-ui.mp4

## 配色 (hex)
- 桌面：径向渐变，中心 #1B1B1D 到边缘 #070708
- 应用窗口：#121212，标题栏 #191919，细线 #232323 和 #262626
- 面板：#1D1D1D，圆角 8 px，面板间 8 px 间隙
- 计划行：#232323，1 px 内线 #2B2B2B，图标方块 #2D2D2D
- 文字：#EDEDED（激活）、#E2E2E2（正文）、#7E7E7E（暗色标签页）
- 时间线片段（应用自身配色，偏灰）：视频 #4C478A 边 #7C76C4，音频 #234A3A 边 #3C7F61，图形 #3E414B 边 #646876
- 暖调叠色：#FF9448（柔光，只用于画面内）
- 强调色：#D97757 陶土色。唯一的强调色。用于光标、焦点环、点击圆环、剪切闪光、AI 制作的每个片段上的 3 px 细线、字幕当前词胶囊、下三分之一条、导出进度条。

## 字体
- 展示字：Switzer 800，字距 -0.03em，行高 1（字幕 72 px，白色，柔和阴影）
- 标签：Switzer 600 到 650，标签页 14 px，工作区标签页 15 px，计划行 21 px，时间码用等宽数字
- 仅限一个词：Instrument Serif 斜体，92 px（字幕行里 AI 的名字）
- 字体链接（粘贴到 <head>；所有字体均免费）：
  <link rel="stylesheet" href="https://api.fontshare.com/v2/css?f[]=switzer@400,500,600,700,800&display=swap">
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@1&display=swap">
- 中文文字用 Noto Sans SC（无衬线），从 Google Fonts 引入，因为拉丁字体没有中文字形：`<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@500;600;800&display=swap">`

## 缓动 (数值)
- 落定：expo.out，0.7 s（面板从缩放 0.975 上升 26 px）
- 离场：power2.in，0.25 到 0.28 s
- 移动：power3.inOut，0.45 s（镜头推进、焦点环、波纹闭合、光标移动）
- 弹出：back.out(2)，0.32 到 0.35 s（片段落下、字幕词）；计划勾选 back.out(2.6)，0.4 s
- 错开：面板 0.07 s，字幕词 0.15 s，列表行 0.03 s
- 节拍：120 BPM，每个打点落在 0.5 s 刻度上

## 动效规则
- 一个时钟驱动一切。镜头、光标、播放头、时间码和调色都是时间的纯函数。
- 镜头是作用在整个 1920x1080 应用上的一条关键帧轨（x、y、缩放、倾斜），透视 2600 px。
- 每次推进都用 power3.inOut，约 0.5 s，推到缩放 1.4 到 2.1，然后在操作进行时缓慢漂移停留（线性放大 2% 到 3%）。
- 根据镜头速度加一点倾斜（每 px/s 0.0016 deg，最大 3 deg），让移动像镜头而不是幻灯片。
- 光标从不瞬移。移动用 power3.inOut，0.3 到 0.5 s，每次点击前停 0.05 s。
- 点击时光标下沉 16%，持续 0.2 s，并落下一个 44 px 陶土色圆环，在 0.45 s 内扩大到 1.7 倍并淡出。
- 光标按镜头缩放的 0.35 次方反向缩放，镜头拉近时仍然可读。
- 一个陶土色焦点环（2 px，内嵌）滑到 AI 正在操作的面板上。

## 标志动作
- AI 面板：右侧一栏（464 px 宽，全高），有一个提示词气泡和六步计划。每行运行时转圈，完成后弹出一个陶土色勾。
- 看得懂的真实剪辑：剃刀在波形的平坦间隙处切下，伴随陶土色闪光；静音段抬起移除（y -16，淡出），波纹闭合，时长计数下降。片段从素材箱拖到 V2 上并吸附。字幕逐词出现，当前词带陶土色胶囊。拖动滑块让画面变暖，然后做一次前后对比擦除。
- 潜入：面板先向外推 26 px，然后沿着从中心出发的方向飞过镜头（z +900 到 +1500，最多转 38 deg，模糊 7 px，power3.in 0.95 s，错开 0.05 s）。Program 面板后退到 z -900 保持干净。镜头（power4.in）让 Program 监视器铺满画面。56 道光线从中心飞出（每三道里一道陶土色）。落地那一拍有一次陶土色径向闪光（screen 混合）。
- 可选吉祥物：一个用代码画的小火花沿时间线跳跃。起跳前压扁，空中拉伸，落地晃动，接触阴影随高度缩小。

## 构图
- 标题栏 44 px，有三个灰点和居中的标签页（Import、Edit、Export）。面板标题 34 px，激活标签页有 2 px 下划线。
- 1920x1080 网格：左上 Source 监视器（552x560），顶部居中 Program（872x560），右侧 AI 面板（464x1020），左下 Project 素材箱，一条 40 px 工具条，底部居中 Timeline（952x452）。
- 时间线：带时间码的标尺，轨道 V3 V2 V1 A1 A2，片段圆角 5 px，白色播放头。
- 应用开场倾斜（缩放 0.80，16 deg 和 -13 deg），1.5 s 内回正铺平成全景。之后每一步推进到一个面板。
- 收尾：最后 3 s 成片全屏，字幕和下三分之一重新构建，缓慢推进 5%（power1.inOut）。
- 整体加 3.5% 胶片颗粒和柔和暗角。

## 带素材
- 用户的口播片段在 Program 监视器里实时播放（1920x1080 视频缩放进 840 px 宽的屏幕）。Source 监视器显示另一个片段。
- 素材箱缩略图是用户自己片段的静帧。用户提供的 B-roll 就是被拖到 V2 上的素材。
- 调色是包在画面素材外层的 CSS filter（saturate 1.22、sepia 0.14、略加对比度），再加一层不透明度 0.3 的 #FF9448 柔光层。
- 潜入之后，用户的画面素材全屏。下三分之一（12 px 陶土色条、深色底板擦入、名字和一行说明）和字幕放在低处。任何东西都不遮挡人脸。
- 没有画面素材？用代码画一个占位场景（话筒前的剪影、台灯、窗户），走同一个时钟。
- 人物默认用 Harry 本人的素材：`assets/me/p1.png`–`p5.png`（已去背景）、`assets/me/photo1.jpg`–`photo5.jpg`（原图）、`assets/me/webcam.mp4`（口播片段）、`assets/me/ai-walk.mp4`（AI 走路片段）、`assets/me/ai-turn.mp4`（AI 转身片段）。文字绝不压在他脸上。

## 禁用清单
- 真实剪辑软件的名称、标志或品牌色
- 界面外框里出现第二种强调色
- 人脸上的文字、光标或吉祥物
- 跳跃的光标，或没有圆环的点击
- 用柔和交叉淡化代替真实操作
- 浅色主题
- 在最终镜头缩放下小到看不清的界面
